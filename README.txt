RUFFA B. MANZANILLA — EDITABLE PORTFOLIO WEBSITE

FILES
- index.html  = all website content and sections
- style.css   = design, colors, spacing, typography
- script.js   = small navigation behavior

HOW TO EDIT
1. Install/open VS Code (or another text editor).
2. Open index.html.
3. Search for the section you want to edit.
4. Replace the text while keeping the HTML tags.
5. Save the file.
6. Double-click index.html to preview it in your browser.

PHOTO
The hero currently has an "ADD PHOTO" placeholder.
When you have Ruffa's professional photo:
- Put the photo in the same folder, e.g. ruffa-photo.jpg
- Replace the placeholder div in index.html with:
  <img class="photo-placeholder" src="ruffa-photo.jpg" alt="Ruffa B. Manzanilla">

FUTURE UPDATES
